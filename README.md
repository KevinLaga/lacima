# La Cima: Shipping, Credit & Harvest Management System

Web application for managing shipping, credit, daily production, warehouse, and blueberry harvest data for an agricultural company.

## Features

- Track shipments, credits, daily production, warehouse inventory, and harvest.
- Generate Excel invoices for each individual shipment or for any date range.
- Filter reports by company, shipped item, and other criteria.
- Automatic calculation of revenue to support accounting.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP, Python
- **Database:** SQLITE

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/KevinLaga/lacima.git
   ```
2. Run the application with Start the venv .\venv\Scripts\Activate.ps1 then start the server using python manage.py runserver
